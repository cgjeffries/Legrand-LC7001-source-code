This is the source code for the Legrand LC7001 lighting control hub that I got from Legrand support upon request in October of 2026. It appears to have been archived from their internal git repo sometime in september of this year.

It appears to contains the source code for vesrion 4.7.x of the LC7001. At the time of writing this, my unit is running 4.7.1, and a quick glance with some LLM assistance in comparison with the firmware binary on my unit shows only very minor differences, so maybe this is roughly 4.7.2 or something like that. Either way, this should be inclusive of all additions are are currently in the latest released firmware.

I saw that the license is GPLv2, so I figured I may as well share it so it's easier to find this code online. Maybe we can keep these units running well past their EOL date.
